# Own the Local Pipeline Runtime

Status note: [ADR 0022](0022-run-ci-before-github-sync.md) supersedes this ADR's
hosted-CI statement and records the current local verification and
platform-support policy.

The Coach Skill installer provisions Stockfish, the Maia runtime, and Maia weights as one versioned Local Pipeline Runtime. It downloads a pinned, checksum-verified Stockfish binary for the current target rather than using an arbitrary system binary. It also pins the Maia container image by digest and the Maia model artifact by version or checksum. Every fact envelope records these provider identifiers with its CLI and schema versions. Installed reviews always use this pinned unit; custom provider paths, endpoints, or models are development-only overrides and must appear in provenance. Docker is the sole v1 host runtime prerequisite, while chenchess owns Maia image pulls, model provisioning, container lifecycle, and health checks. Review commands start the runtime when needed and never ask the Player to configure those providers or download dependencies during a review. Maia remains running for later reviews and live evaluations until the Player stops it or uninstalls. One live command owns the runtime at a time; concurrent live callers receive a busy error, while recorded-evidence evaluation remains independent. The first packaged runtime is certified on Apple Silicon macOS; explicit deployment and multi-platform image builds exercise Linux, while Windows is not verified on every change. Each future runtime supplies its own provider artifacts and live baselines. This makes installation heavier, but it turns the skill into a repeatable way to exercise and evaluate the real pipeline rather than a thin client for separately managed services.
