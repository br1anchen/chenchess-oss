# Evaluate deterministic facts separately from prose

Pipeline Evaluation uses a repository-owned PGN corpus to compare pinned Rule Extraction outputs across working-tree and Local Pipeline Runtime versions. Fast evaluation runs the Rule Extractor against recorded provider evidence and compares canonically formatted facts exactly. A separate live mode refreshes that evidence through Stockfish and Maia to verify adapters and expose provider drift; it permits documented numeric tolerances but fails on changed moves, ranks, categories, or Critical Moment selection. Evaluation fails on baseline differences by default, and an explicit acceptance command records updated evidence, fact packets, and a readable diff. It does not invoke Codex, Claude, or another hosted model. This keeps chess-pipeline regressions reproducible and cheap to inspect, while separate manual skill evaluations cover the quality and grounding of agent-authored prose.
