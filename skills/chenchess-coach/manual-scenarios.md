Run these scenarios with the installed skill and Local Pipeline Runtime. Use the canonical fixture journey where a fixed Game is required.

1. **Canonical Lichess URL:** review `https://lichess.org/Synthet1Demo/black`. Confirm strict import, metadata Elo resolution, a validated chronological Game Review, Opening Identification provenance, Review Side Black, and fully prepared objective Review Moments.
2. **Shared Chess.com computer Game:** review `https://www.chess.com/game/computer/1403674481` as White. Confirm strict fixed-origin import, metadata Elo resolution, 80 legal plies ending in `c1=Q`, Chess.com provenance, and fully prepared objective Review Moments.
3. **Shared Chess.com live PvP Game:** review `https://www.chess.com/game/live/100000000001` as White. Confirm strict live-game import, two non-computer Players, metadata Elo resolution, 29 legal plies ending in `c4`, Chess.com provenance, and fully prepared objective Review Moments.
4. **Pasted PGN:** paste the canonical fixture PGN with explicit Review Side and Elo. Confirm the CLI-created command FIFO carries the complete import envelope even when it exceeds 1024 bytes, no PGN appears in command arguments or terminal stdin, and the prepared Review Moments and grounded objective facts match the URL journey after provenance normalization.
5. **Local-file privacy:** provide the canonical PGN path. Confirm only `localPgnFile.path` crosses the agent/CLI boundary; raw PGN never enters agent context, and the chronological Review Session prepares without any Central Host upload.
6. **Pipeline-selected moment:** open a returned Critical Moment with `pipelineCriticalMoment`. Confirm the occurrence ID, Position Snapshot, board, evaluation, and facts match the Game Review.
7. **Player-selected moment:** select a legal ply that the pipeline did not choose. Confirm `playerSelectedMoment` succeeds for either side and shows a Review Engine-produced position view.
8. **Player plan discussion:** discuss the comment's uncertain hypothesis naturally and confirm that no confirmation, correction, skip, clarification, or assessment control appears and no Review Session command is sent automatically.
9. **Player Plan Evaluation:** optionally prepare authoritative facts, author one concise evaluation from the Player's current words, and admit it. Confirm exactly one Language Layer exchange, invented chess literals fail closed, unavailable is terminal, and neither the wording nor result changes or survives in Review Session state.
10. **Alternative Move and targeted coaching:** explore at least two legal plies, revisit the root, branch again, inspect every explained Position, start a Coach Turn, author from `coachTurnPrepared.facts`, publish, and show only the completed assessment.
11. **Cancellation and steering:** cancel active provider work, confirm no branch commits, then steer a Coach Turn while preserving its target unless the new message explicitly retargets it. Confirm stale publication is rejected.
12. **Fork Learning Path:** review a Game with a validated Fork track. Confirm Improvement support renders `Missing Idea · Fork` in the `Piece Coordination` cluster, followed by the exact `Concept lesson` / `The Fork` and `Pattern drilling` / `Fork`, without a Real-game application stage. Reinforcement support says `Idea Reinforced`. Rank and selection metadata stay hidden.
13. **Hanging Piece Learning Path:** review a Game with a validated Hanging Piece track. Confirm its supporting automatic moment renders `Missing Idea · Hanging piece` in `Piece Coordination`, explicitly says no exact Lichess Practice module was mapped, retains the grounded coach explanation as the concept lesson, links the exact `Pattern drilling` / `Hanging piece` stream, and does not repeat the supporting move as application practice.

Confirm its ply-112 Endgame moment renders `Promotion resource` in the `Pawn Play` cluster, uses the grounded explanation when no exact Practice module exists, links only the exact `Pattern drilling` / `Promotion` stream, and does not repeat the supporting move as application practice.
16. **Empty Learning Plan:** review a Game whose `learningPlan.tracks` and moment `learningMaterial.tracks` are empty. Confirm the rendered review omits learning links and emits no generic lesson or training advice.
17. **Player-selected Local Learning Tracks:** open a non-Automatic ply whose audited first move creates a Fork.
